# パパノート

スマホからひとこと・写真・タグで育児の記録をさっと残して、あとで振り返るためのパパの記録帳です。

## できること

- **書く**：ひとこと、タグ（はじめて / お風呂 / 寝かしつけ など）、写真1枚を数秒で記録
- **タイムライン**：日ごとに並び、「生後○日」が付く
- **ふりかえる**：1週間前・1ヶ月前・1年前の同じ日、月ごとのまとめ、はじめてコレクション、タグ別の読み返し
- **バックアップ**：記録と写真をJSONファイルに書き出し・読み込み

## データの保存場所

記録と写真は**そのスマホのブラウザの中（IndexedDB）だけ**に保存されます。サーバーには送られず、このリポジトリにも含まれません。

- 機種変更やブラウザのデータ削除で消えるため、設定画面の「ファイルに書き出す」でときどきバックアップしてください
- iPhone の Safari は、ホーム画面に追加せずに使うと、しばらく開かなかったときにデータが消えることがあります。**必ずホーム画面に追加して使ってください**

## 公開方法（GitHub Pages）

1. GitHub で新しいリポジトリ（例：`papa-note`）を作る
2. このフォルダのファイルをすべてアップロードする
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/papa-note/` で開けるようになる

## スマホのホーム画面に追加する

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：メニュー →「ホーム画面に追加」または「アプリをインストール」

## 更新するとき

`index.html` などを変更したら、`sw.js` の `CACHE` の番号（`papa-note-v1` → `v2`）を上げてください。上げないと、スマホに古い版が残り続けることがあります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JavaScript） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインでも開けるようにするキャッシュ |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アプリアイコン |
